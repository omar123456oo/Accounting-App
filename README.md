# Accounting Office Management System

Angular (frontend) + Node/Express/MongoDB API (`backend-mongo/`), for Egyptian accounting offices.

The Laravel + PostgreSQL API in `backend/` is the original Phase 1 stack. It is frozen: no new work goes there, and `backend-mongo/` is the active API. Setup for the active API: `docs/setup-mongodb.md`.

- Roadmap spec: `docs/specs/2026-10-12-accounting-office-system-roadmap-design.md`
- Phase 1 plan: `docs/plans/2026-10-12-phase-1-foundation.md`

Quick start: see `docs/setup.md`. The frontend runs on its own (`cd frontend && npm start`) with an in-memory mock API.
